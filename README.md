# 🛒 Shopify Sales Data Analysis Project

A complete Data Analytics and Data Science project built using Python, SQL, and Power BI to analyze Shopify sales data and generate meaningful business insights.

---

# 📌 Project Objective

The objective of this project is to analyze Shopify sales data to identify:

- Sales trends
- Customer behavior
- Top-performing products
- Country-wise revenue
- Payment gateway usage
- Revenue forecasting
- Customer segmentation

This project helps businesses make data-driven decisions using analytics and visualization techniques.

---
